# Changelog

## [0.1.0] - 2026-10-21

First public release of **Bases Enhancements**.

- Star saved Bases views from the view dropdown or Configure view.
- Switch layouts from centered favorite tabs with native icons.
- Reorder favorites by dragging, keyboard, or context menu.
- Keep favorites per base across panes, file sync, view renames, and file-backed embeds.
- Scroll the tab bar in narrow panes and navigate it with the keyboard.
- Hide empty native Kanban fields, labels, and placeholders with a per-view toggle. Cards shrink and columns close the gaps.
- Highlight clickable Kanban cards on hover and keyboard focus.
- Document and verify native folder-aware note creation, inherited properties, and visible unassigned Kanban groups.
- Keep the original `bases-view-favorites` installation ID so existing installations and command bindings continue to work.
